12 / Methodology and limitations

The dashboard reads point coordinates in WGS84 longitude/latitude. Leaflet displays coordinates as latitude, longitude, while GeoJSON uses longitude, latitude. Buildings, compounds, households and population are treated as separate input attributes. The dashboard does not infer missing counts. Grid hotspot results are exploratory, based on the selected variable and grid size. Results depend on point coverage, coordinate quality, selected filters and spatial resolution.
