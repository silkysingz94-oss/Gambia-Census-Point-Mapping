Methodology

Getis-Ord Gi*: identifies local concentrations of high and low values using the complete rectangular grid and selected queen or rook neighbourhood. Normal-approximation p-values are adjusted across grid cells using the Benjamini-Hochberg false discovery rate (FDR) procedure. The 90%, 95% and 99% classes use adjusted q-value thresholds of 0.10, 0.05 and 0.01.

Global Moran's I: measures overall spatial autocorrelation using grid adjacency and a permutation test.

Local Moran's I (LISA): classifies cells as High-High, Low-Low, High-Low or Low-High based on standardized cell values and neighbouring spatial lags. Local permutation significance is not calculated here; interpret these as exploratory cluster/outlier classes.

Gini coefficient: summarizes inequality in population values across Compounds/buildings, from 0 (equal values) towards 1 (greater inequality).

Pearson and Spearman correlations: quantify linear and rank-based relationships between population, households and Buildings. Correlation does not imply causation.

Nearest-neighbour analysis: compares observed mean nearest-point distance with the expected distance under complete spatial randomness. The calculation uses the points' projected bounding rectangle and an approximate local equirectangular projection.

Spatial outliers: flags grid cells whose value differs from the mean of adjacent cells by at least two global standard deviations. This is an exploratory screening rule, not a formal significance test.

KDE: shows smoothed spatial concentration and is not a significance test.

Limitations: grid cells cover the selected points' bounding rectangle, not necessarily the exact administrative polygon. The local equirectangular projection is an approximation for regional analysis. Check coordinate reference systems and study-area boundaries before formal publication.
